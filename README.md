# Projeto Mairink — Node.js + Sequelize

Projeto adaptado para a avaliação individual de Node.js.

## Tecnologias

- Node.js
- Express
- Sequelize (ORM)
- SQLite (banco de dados relacional)
- Jest + Supertest (testes automatizados)
- Interface HTML

## Estrutura

O projeto possui uma API REST para gerenciamento de produtos, utilizando:

- Controllers
- Services
- Routes
- Models
- Sequelize
- Banco de dados SQLite
